## Intended audience

This lesson is for researchers who use R and want to make their analyses more reproducible, maintainable, and easier to share.

Learners should have some programming experience and either:

- Be comfortable using R, including running scripts, working with data frames, writing simple functions, and managing packages.
- Be experienced in another programming language (such as Python) and have some familiarity with R syntax.

You do not need to be an expert in R, but this lesson assumes an understanding of basic programming concepts and does not cover programming fundamentals.
